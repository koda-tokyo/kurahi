# エディション

English: [Editions](/editions)

Kurahiは1つのランタイムを4つのエディションで提供します。エディションごとに、対象となる組織に合わせた
ホーム画面、ナビゲーション、用語、標準のエージェント構成を備えています。基盤はすべて同じKurahiで、
セキュリティモデルも共通です。

| エディション   | 対象                                                                  | 主な作業画面                           |
| -------------- | --------------------------------------------------------------------- | -------------------------------------- |
| **Industrial** | 生産技術、運用、保全、レガシーのモダナイゼーション、OT/ITセキュリティ | 設備・システム全体の状態と進行中の業務 |
| **Business**   | バックオフィス：案件、文書、ワークフロー、承認                        | 案件と業務プロセスの管理画面           |
| **Scholars**   | 大学・研究機関。研究（Research）と教育（Education）で別々のレイアウト | 研究とノートブック、授業               |
| **Core**       | まだ専用エディションを必要としない分野のチーム                        | チャット中心のプロジェクト管理画面     |

## すべてのエディションに共通する部分

エディションは1つの基盤の上の構成です。次の部分はすべてのエディションで共通であり、エディションの側から
弱めることはできません。

- ID、プロジェクトとそのフォルダ境界、権限、コネクタ
- チャットとプッシュ・トゥ・トーク（押して話す）による入力
- 作成元とエクスポート時のハッシュを持つ、バージョン管理された成果物
- 承認と権限の申請
- 署名付きのタイムラインと証跡の来歴
- セキュリティモデル：ポリシー、サンドボックス、実行承認、監査ログ、サプライチェーンロック、
  メモリの来歴管理、署名付きエージェント間メッセージ（[セキュリティ概要](/ja/security/SECURITY_OVERVIEW)を参照）

エディションの定義（マニフェスト）が扱うのは、表示と必要な機能だけです。権限、プロジェクトの分離、
セキュリティ、承認、監査のポリシーを設定する項目はありません。画面遷移と権限は機能の有無から決まり、
画面上で隠すことで制御するものではありません。未接続や無効のコネクタも、現在の状態のまま表示されます。

すべてのエディションで、提供開始時の言語は日本語と英語です。

## 機能パック

エディションの中の各業務領域は、機能パックとして提供します。パックはエージェント、ツール、テンプレート、
画面を追加しますが、全体のナビゲーションを増やしたり、エディションのポリシーを変えたりはしません。
各パックはコンソールで準備状況を表示します：有効、設定済み、無効、計画中。

Industrialエディションには現在5つのパックがあります。

| パック               | 準備状況 | 対象                                                                    |
| -------------------- | -------- | ----------------------------------------------------------------------- |
| 分析（Analysis）     | 有効     | 決定的なレガシー解析（COBOL/JCL、Java、SQL DDL）。事実ごとにpath:line   |
| モダナイゼーション   | 設定済み | 移行先の設計、変換計画、同等性の証跡                                    |
| 保全（Maintenance）  | 設定済み | 作業指示、マニュアル、状態データ（各接続の設定後）                      |
| 制御（Controls）     | 無効     | オフラインでのPLCレビュー。承認済みのオフライン出力が接続されるまで無効 |
| サイバーセキュリティ | 計画中   | 認可された範囲の資産台帳と検出事項のレビュー。スキャナー接続は未提供    |

### Researchパック（計画中）

Researchパックは、Scholarsの研究用ワークスペース（研究、ノートブック、データ、実験、文献、来歴）を
IndustrialとBusinessのエディションに追加するアドオンとして計画しています。研究開発部門での利用などを
想定しています。現時点では提供していません。

## 現在利用できるものと計画中のもの

2026年10月25日時点、リリース2.2.0。提供中か予定かは状況の列に示します。

| 項目                                             | 状況                                                                                                                                                                                                                                                           |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| エディションとワークスペースの定義（4種）        | 実装済み：共通の基盤が、エディションごとのナビゲーション、用語、レイアウトを切り替える                                                                                                                                                                         |
| Industrialエディションのワークベンチ             | 実装済み：最初の基準となるエディション。上記5つのパックを含む                                                                                                                                                                                                  |
| レガシー解析と設計書の生成                       | 実装済み：[産業向けモダナイゼーション](/ja/industrial-modernisation)を参照                                                                                                                                                                                     |
| Work Consoleのターミナルとプッシュ・トゥ・トーク | 実装済み：Industrialプロジェクトのターミナルはゲートウェイのブローカー経由で動作。音声入力と書き起こしの確認はプレビュー。実行履歴は開発中（[Work Console](/ja/work-console)を参照）                                                                           |
| Businessエディション                             | プレビュー：承認ルート（稟議）付きのワークキュー。コンソールで経費申請、承認・差し戻し、下書きのプレビュー、証跡の検証が可能。15の部門ワークスペース（[ワークキュー](/ja/business/work-queue)を参照）                                                          |
| オートパイロット（全エディション）               | 実装済み：プロジェクトごとのルーティンを自律レベルL0〜L3で実行。常設承認、トリガー、挙動監視、全体停止、朝のブリーフ。ルーティンは定義したプロジェクトでのみ実行（テンプレートには初期ルーティンを含む）（[オートパイロット](/ja/autopilot)を参照）            |
| エンタープライズIDとエンタープライズパッケージ   | 実装済み：OIDC・SAMLによるサインイン、SCIM、役割（既定は無効）。コンシューマー向けチャネルを含まないエンタープライズパッケージ（[エンタープライズID](/ja/security/identity)、[エンタープライズプロファイル](/ja/security/enterprise-profile)を参照）           |
| 業務コネクター                                   | プレビュー・既定は無効：[Microsoft 365](/ja/connectors/microsoft-365)、[Gmail](/ja/connectors/gmail)、[Entra ID](/ja/connectors/entra) と日本の SaaS コネクター 6 種（[業務コネクター](/ja/connectors) を参照）                                                |
| Scholarsエディション（研究、次に教育）           | 計画中：ナビゲーションは定義済み。研究と教育の画面は未実装。研究・学術プロジェクトテンプレートで新着文献ウォッチ、引用チェック、研究費の締切リマインダーを利用可能（[学術情報源](/ja/connectors/scholar-sources)、[オートパイロット](/ja/autopilot#scholars)） |
| Coreエディション                                 | 計画中：他のエディションで実績を積んだ共通部品から最後に構成                                                                                                                                                                                                   |
| Researchパック                                   | 計画中                                                                                                                                                                                                                                                         |
| エディションのライセンス                         | 計画中：ライセンスの識別子は定義済み。条件と価格は未公開                                                                                                                                                                                                       |

提供の順序は、Industrial、Business、Scholars（研究、次に教育）、Coreです。代表的な利用者が、
汎用チャットを経由せずに主要な3つの業務を完了でき、エージェントのすべての操作を共通の証跡モデルで
追跡できる状態になった時点で、そのエディションの準備が整ったものとします。

## Scholars：非営利の学術利用は無償

Scholarsは、所在国を問わず、大学・研究機関での非営利の研究と教育に無償で使えるグローバルなエディションとして
計画しています。商用利用には商用ライセンスが必要です。申請受付はまもなく開始します。
詳しくは[Kurahi Scholars](/ja/scholars)をご覧ください。
