# Kurahi 2.6.0

English: [Kurahi 2.6.0](/releases/2.6.0)

Kurahi 2.6.0 では、Kurahi Industrial がレガシーシステムの理解から一歩進み、変更が意図どおりに動くことを
証明できるようになりました。Kurahi は KODA SōKEN チームが開発しています。変更の一覧は
[変更履歴](https://github.com/koda-tokyo/kurahi/blob/main/CHANGELOG.md)をご覧ください。

2.6.0 でできること：

- **COBOL・FORTRAN プログラムの変更を検証する。** 変更前と変更後のプログラムをコンパイルし、同じテスト入力で
  実行して出力を比較します。承認済みの変更と、意図しない差異（デグレード）を区別し、すべての結果を
  オフラインで検証できる署名付き証跡として残します。
- **既存の分析結果を取り込む。** Google Cloud Mainframe Assessment Tool、AWS Transform for mainframe、
  IBM watsonx Code Assistant for Z（Z Understand）の結果を、Kurahi 自身の分析と並べて扱えます。
- **攻撃者より先に、自社の露出を知る。** Guardian の露出チェックが、自社が所有するドメインと、同意した
  従業員の露出を確認します。

[変更検証](/ja/industrial/verification)、[ベンダー結果の取り込み](/ja/industrial/vendor-import)、
[Kurahi Guardian](/ja/security/guardian) をご覧ください。

## 新機能

### Kurahi Industrial

- **変更検証**（`modernise_verify`、`kurahi legacy verify`）：ソースのスナップショット（ファイルごとの SHA-256
  とコンパイラー情報）、GnuCOBOL・GNU Fortran、既定はバイト単位の完全一致、またはパック 10 進（COMP-3）を
  含む項目単位の比較（許容差は明示、既定 0）。承認済みの変更仕様で意図した変更とデグレードを区別します。
  判定は PASS、FAIL、INCONCLUSIVE、TIMEOUT、CANCELLED、NOT_RUN_NO_FIXTURES、
  NOT_RUN_COMPILER_UNAVAILABLE。PASS は実行したテスト入力の範囲に限られます。GnuCOBOL は IBM Enterprise
  COBOL ではありません。PL/I は解析でき、検証はライセンスのある PL/I コンパイラーを設定した場合のみです。
- **変更案件：** 承認者は担当者・申請者と別の人であること。候補・仕様・ポリシー・入力のいずれかが変わると
  承認は取り消されます。承認は引き渡しまでで、本番へのデプロイは行いません。
- **すべての結果に署名付き証跡**、`kurahi evidence verify --trust-key`。
- **ベンダー結果の取り込み**（`modernise_import`、`kurahi industrial import`）：Google MAT（Neo4j グラフの
  エクスポート）、AWS Transform for mainframe（生成された要件）、IBM Z Understand（生成されたドキュメント）を
  各社の公開形式に沿って取り込みます。その他の形式は、お客様が用意する項目対応表で取り込めます。
  バンドルはサイズ・パス・ハッシュを確認し、マルウェア検査を行い、署名付き証跡として記録します。取り込んだ
  結果は、レビューされるまで未検証のベンダーの見解として表示します。Kurahi がこれらのベンダーサービスに
  接続したり実行したりすることはありません。

### Kurahi Guardian

- **露出チェック**（`guardian.exposure`）：所有を確認したドメインについて、証明書透明性ログのサブドメイン、
  SPF・DMARC・MX・CAA とダングリング CNAME、自社サイト上の秘密情報（マスク表示）、類似ドメイン。任意で
  Have I Been Pwned のドメイン検索、GitHub のコード検索。
- **個人の露出（同意に基づく、既定で無効）：** 登録し、自分の連絡先を確認した人だけが対象。結果は本人と
  セキュリティ担当だけが見られます。同意はいつでも取り消せます。登録していない人を検索することはありません。

### ドキュメント

- 英語ページは英語のみになりました。日本の業務用語は用語集で対応を示しています。

## 2.5.0 からのアップグレード

`kurahi update`（または `--version 2.6.0` を付けた `install.sh` / `install.ps1`）で通常どおりインストール
できます。[アップデート](/ja/install/updating)をご覧ください。2.5.0 の設定はそのまま読み込まれ、新機能は
設定するまで無効です。変更検証にはサーバーに GnuCOBOL（`cobc`）または GNU Fortran（`gfortran`）が必要です。
ない場合の判定は NOT_RUN_COMPILER_UNAVAILABLE です。

## ロールバック

`install.sh --version 2.5.0`（Windows：`install.ps1 -Version 2.5.0`）で 2.5.0 に戻せます。2.5.0 を起動する前に、
設定から `guardian.exposure` を削除してください。2.6.0 で作成した検証結果・変更案件・取り込みはディスクに
残りますが、2.5.0 にはそれらを扱う機能はありません。

## 注意事項

- Kurahi はセルフホスト型です。お客様のサーバーと、お客様が選ぶ提供者は Kurahi とは別です。
- すべての配布物のチェックサムは `SHA256SUMS.txt` と `SHA256SUMS-desktop.txt` にあります。
