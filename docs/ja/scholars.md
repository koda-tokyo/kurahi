# Kurahi Scholars

English: [Kurahi Scholars](/scholars)

**申請受付はまもなく開始します。** このページは、研究者や教員の方が事前に準備できるよう、
プログラムの内容をご紹介するものです。現時点で申請いただけるものはありません。プログラムの内容と条件は、
申請受付の開始までに変更となる場合があります。

Kurahi Scholarsは、Kurahiの学術向け[エディション](/ja/editions)です。大学・研究機関における非営利の
研究と教育であれば、所在国を問わず無償で利用できます。確認するのは、制裁や輸出管理など法令で
KODA SōKENに義務づけられている事項だけです。開始時の対象は大学・研究機関で、学校は後日の対象となります。

## 研究・教育のワークスペース（提供予定）

Scholarsには、役割に応じて切り替わる2つのワークスペースがあります。

| ワークスペース    | 対象   | 内容                                                   | 状況     |
| ----------------- | ------ | ------------------------------------------------------ | -------- |
| 研究（Research）  | 研究者 | 研究、データ、実験、文献、来歴、論文                   | 提供予定 |
| 教育（Education） | 教員   | 授業、レッスン、課題、チューター、ポートフォリオ、進捗 | 提供予定 |

ワークスペースは基盤上で定義済みですが、画面はまだ実装されていません。役割の切り替え、ノートブックや
計算クラスタとの連携、授業用のサンドボックス、文献サービスとの連携も計画中で、現在は利用できません。

## 現在利用できるもの

専用のワークスペース画面ではなく、Kurahiのプロジェクト機能を通じて利用できます。

- **研究・学術**プロジェクトテンプレート：無料の文献 API（[学術情報源](/ja/connectors/scholar-sources)：arXiv、OpenAlex、Crossref、PubMed。キー不要）を使う 3 つの[オートパイロット](/ja/autopilot#scholars)のルーティン（研究プロフィールに基づく毎週の新着文献ウォッチと Word のダイジェスト、原稿の引用チェック、研究費の締切リマインダー）。投稿・申請は一切しません。資料は読み取り専用で、すべての主張に出典ファイルを示す
- 教員の授業計画のための**教育**テンプレート（学習者の個人データは扱わない）
- 証跡バンドル：エージェントの各ジョブの署名付き記録を、オフラインで検証できる
- ハッシュチェーンの監査ログ、ポリシー・アズ・コード、人による承認
- 実行されたものの署名付きAIインベントリ
- メモリの来歴管理とコンテキストガード
- ワークフロー評価：受け入れ基準、オフラインでの再現、署名付きの評価結果
- ソフトウェア工学の研究に使える、COBOL/JCL、Java、SQL DDLのレガシー解析

Kurahiは所属機関またはご自身のマシンで動作し、KODA SōKENにテレメトリを送信しません
（[プライバシー](/ja/security/privacy)）。モデルはホスティング型でもローカルでも自由に選べ、
モデルの利用料と計算資源はご自身でご用意いただきます。ビルドにはまだコード署名がありません。

## トラック

| トラック     | 対象                                                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------------------------- |
| Scholar      | 研究者、教員、指導を受ける学生の個人。所属機関のない研究者は、認められた機関の研究者による推薦状があれば参加可能          |
| Research Lab | 1人の研究代表者または教員のもとで活動するグループや授業。ポリシー、監査ログ、証跡を共有。最大25名、所属機関が契約の当事者 |
| Fellow       | オープンで検証可能なエージェント研究や教育を前進させる取り組みを、提案内容の選考で支援。詳細は追ってお知らせします        |

## 研究成果を発表する自由

- Kurahiを使って、またはKurahiについて得た知見は、ベンチマーク、失敗、ネガティブな結果を含め、
  KODA SōKENへの事前の相談や審査なしに発表できます。
- 唯一の例外は、他の利用者を危険にさらすおそれのある脆弱性です。`SECURITY.md` の手順でまず報告してください。
  協調的開示の期間は最長90日で、対象は攻撃に必要な詳細だけです。
- データ、コード、論文、研究成果はすべて研究者ご自身のものです。

## 対象外となるもの

- 企業の研究開発（企業内の研究所を含む）。こうした用途向けには有償のResearchパックを計画しています。
- 企業の製品、サービス、社内業務のための作業。
- モデルの利用料、計算資源、ホスティング、応答時間を保証するサポート。

Scholarsは、所属機関の倫理審査や個人情報保護に関する承認に代わるものではありません。
