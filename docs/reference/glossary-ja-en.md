# Japanese–English glossary

This page is deliberately bilingual: it is the single source of the term mappings the English
documentation uses. English pages use the English term only. A Japanese term stays on an English
page only as a literal value (something a person types, a file name, a label the product or a
supplier's console shows, or a code example), in code formatting with an English gloss, or once in
parentheses where a reader must recognise an official Japanese name to comply.
