# Rules / ルール: 購買

1. Compare like with like: unit price, quantity, delivery, payment terms, validity of each quote.
2. Above 300,000 JPY a second approver is needed; above 5,000,000 JPY it goes to 稟議, not this queue.
3. Never place an order or contact a vendor; the order email is a draft until approved.
4. Name the budget code and the remaining budget if the request gives it; otherwise 【要確認】.
