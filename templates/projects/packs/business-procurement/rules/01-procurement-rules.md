# Rules / ルール: 購買

1. Compare like with like: unit price, quantity, delivery, payment terms, validity of each quote.
2. Above 300,000 JPY a second approver is needed; above 5,000,000 JPY it goes to 稟議, not this queue.
3. Never place an order or contact a vendor; the order email is a draft until approved.
4. Name the budget code and the remaining budget if the request gives it; otherwise 【要確認】.

5. Compare whole-request tax-exclusive net only among quotes covering every requested code at the requested quantity. Missing items are not free; quantity differences make the quote incomplete. Preserve ties and report no overall lowest when no quote is complete. 依頼全品目・数量が一致する完全な見積だけを税抜純額で比較します。欠落を無料扱いせず、数量差は不完全とします。同額を残し、完全な見積がなければ全体最安なしとします。
6. Item-level lowest prices are not an award or proof of a complete quote. A person decides after reviewing delivery, validity, terms and quality; record order confirmation separately. 品目ごとの最安は選定済みや完全見積の証明ではありません。人が納期・有効期限・条件・品質を確認して決定し、発注確認は別途記録します。
