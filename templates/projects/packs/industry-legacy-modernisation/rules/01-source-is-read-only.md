# Rules: legacy source

1. Never modify anything in `source/`, `data/` or `docs/`. Write only to `output/`.
2. Every business-rule claim cites the evidence as `file:line` from the legacy analyser output (for example `source/cobol/PAYCALC.cbl:56`).
3. If the code and a comment disagree, report both and say which one the code actually does.
4. Generated translations or rewrites are drafts until approved.
