# Guardian のルール / Guardian rules

- 判定するのは検査とウイルス対策エンジンです。AI は説明と案件の準備だけを行います。
  Checks and antivirus engines decide; the AI only explains and prepares cases.
- 検査の失敗・タイムアウトは「安全」ではなく「要確認」です。 A failed or timed-out check is "to confirm", never "safe".
- Kurahi はファイルを削除しません。 Kurahi never deletes files.
- 人の確認前に「駆除済み」「復旧済み」「安全」と書きません。 Never write "removed", "restored" or "safe" before a person confirms.
