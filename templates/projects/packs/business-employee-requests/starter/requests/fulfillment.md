# Fulfillment record / 実施記録

Manual worksheet for an existing request; keep its case ID. This file does not update
queue status, send messages or perform work. Approval alone is not completion.
既存申請の案件IDを使う手動記録です。状態更新・送信・実施は行いません。承認だけでは完了ではありません。

| Record / 記録                                                                         | Value / 記入欄    |
| ------------------------------------------------------------------------------------- | ----------------- |
| Case ID and reviewed revision / 案件ID・確認した版                                    |                   |
| Request form and version / 申請原本・版                                               |                   |
| Approved scope and decision reference / 承認範囲・判断参照                            |                   |
| Responsible person / 実施責任者                                                       |                   |
| Actual outcome / 実際の結果                                                           | Pending / 未実施  |
| Performed at, with timezone / 実施日時・タイムゾーン                                  |                   |
| System-of-record evidence reference / 正式記録の証跡参照                              |                   |
| Remaining work, owner and next check / 残作業・担当・次回確認                         |                   |
| Requester communication: sender, time, reference / 申請者への連絡：送信者・日時・参照 | Not sent / 未送信 |
| Closure reviewer and date / 完了確認者・日付                                          |                   |

Record partial, failed or cancelled outcomes explicitly; do not mark complete while
required work or confirmation remains unknown. A draft reply is not a sent message.
部分実施・失敗・取消はそのまま記録し、必須作業や確認が不明なまま完了としない。返信下書きは送信済みではありません。

- Equipment/cards: distinguish ordered, delivered and received; record outstanding quantities.
  備品・名刺：発注・配送・受領を分け、未受領数量を記録。
- Facilities: record the actual reservation reference, date, time zone and time slot;
  the requested dates do not prove a booking or absence of conflicts.
  施設：実際の予約参照・日付・タイムゾーン・時間枠を記録。希望日だけでは予約・重複なしを確認できません。
- Certificates: an authorized person verifies issuance and delivery separately. Keep only
  restricted evidence references here, not certificate contents or identity documents.
  証明書：権限者が発行と交付を別々に確認。ここには閲覧制限された証跡の参照のみを記録し、証明書本文・本人確認書類を転記しない。

If the approved scope changes, retain the original decision and request a fresh review
before further work. Correct evidence by adding a dated entry with author, reason and
the replaced reference; preserve the previous record.
承認範囲の変更時は元の判断を保持し、追加実施前に再確認を依頼。証跡の訂正は記録者・日時・理由・旧参照を追記し、旧記録を保持。
